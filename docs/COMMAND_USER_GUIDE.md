# 智能命令系统 - 用户指南

## 🎯 快速开始

### 输入 `/` 查看所有命令

```
> /
```

### 输入 `/m` 模糊匹配 `/model`

```
> /m
```

### 使用上下键导航

```
↑ 向上选择命令
↓ 向下选择命令
Enter 执行命令
Esc 取消
```

---

## 📋 命令列表

| 命令 | 描述 | 快捷键 |
|------|------|--------|
| `/model` | 选择 AI 模型 | `+ m` |
| `/settings` | 打开设置页面 | `+ s` |
| `/clear` | 清空消息历史 | `+ c` |
| `/help` | 显示帮助 | `+ h` |
| `/exit` | 退出程序 | `+ e` |

---

## 🔍 模糊匹配

输入命令的前几个字母即可自动匹配：

| 输入 | 匹配 |
|------|------|
| `/` | 所有命令 |
| `/m` | `/model` |
| `/s` | `/settings` |
| `/c` | `/clear`, `/config` |
| `/h` | `/help` |
| `/e` | `/exit` |

---

## ⚠️ 注意事项

1. **命令必须以 `/` 开头**
2. **命令不会发送给 AI Agent**
3. **只有匹配的命令才会执行**
4. **未知命令会显示错误提示**
