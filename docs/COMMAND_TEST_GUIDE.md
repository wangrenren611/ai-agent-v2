# 命令列表测试指南

## ✅ 已修复的问题

### 问题：输入 `/` 时命令列表不显示

**原因**:
- `useMemo` 的依赖项在某些情况下可能不会立即触发重新计算
- React 的批处理更新导致状态更新和重渲染不同步

**解决方案**:
- 移除了 `useMemo`
- 直接计算 `matchedCommands`: `const matchedCommands = input.startsWith('/') ? matchCommands(input) : [];`
- 确保每次渲染时都重新计算匹配结果
